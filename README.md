# 🌱 Agrinho

O **Agrinho** é um projeto desenvolvido com o objetivo de promover soluções tecnológicas para o setor agrícola, auxiliando no gerenciamento, monitoramento e organização das atividades no campo. A aplicação busca facilitar o dia a dia dos produtores por meio de ferramentas simples, práticas e acessíveis.

## 🚀 Funcionalidades
- Monitoramento agrícola
- Organização de informações do campo
- Interface simples e intuitiva
- Gestão eficiente de atividades rurais

## 🛠️ Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## 📚 Objetivo
Incentivar a inovação e a sustentabilidade no meio rural através da tecnologia.
