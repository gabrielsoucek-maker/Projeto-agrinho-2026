# 🍓 Simulador de Estufa de Morango Inteligente - Agrinho 2026

## 🌾 Sobre o Projeto
Este projeto foi desenvolvido especialmente para a participação no **Concurso Agrinho 2026**, abraçando o tema **"Agro forte, futuro sustentável: o equilíbrio entre produção e meio ambiente"**. 

A aplicação é um simulador web interativo que replica o ecossistema de uma estufa automatizada para o cultivo de morangos. O objetivo principal é demonstrar como a **agricultura de precisão** e a tecnologia aplicada ao campo podem otimizar a produção de alimentos enquanto protegem os recursos naturais, evitando o desperdício de água e o uso excessivo de energia elétrica.

---

## 🛠️ Funcionalidades
* **Simulador Interativo:** Painel com controles deslizantes (sliders) para regular em tempo real a Temperatura, Umidade do Ar e Umidade do Solo.
* **Análise Agronômica Dinâmica:** O sistema processa os dados inseridos e informa instantaneamente se as condições estão ideais, regulares ou críticas para o desenvolvimento do morangueiro.
* **Foco em Sustentabilidade:** O simulador alerta o usuário caso as configurações gerem desperdício de recursos hídricos (como solo encharcado) ou sobrecarga energética dos equipamentos.
* **Navegação SPA (Single Page Application):** Interface moderna que alterna entre o simulador e as páginas informativas sem a necessidade de recarregar o navegador.

---

## 🍃 Alinhamento com o Tema do Agrinho
O projeto prova que o "Agro Forte" não precisa caminhar separado da preservação ambiental. Através do monitoramento inteligente demonstrado no código:
1. **Economiza-se Água:** A irrigação baseada na umidade real do solo impede o desperdício.
2. **Economiza-se Energia:** Os sistemas de ventilação e aquecimento só atuam quando estritamente necessário.
3. **Maximiza-se a Produção:** A planta cresce em seu ambiente perfeito, gerando frutos de melhor qualidade com menor impacto ecológico.

---

## 💻 Tecnologias Utilizadas
O projeto foi construído do zero, utilizando tecnologias web fundamentais de forma limpa e eficiente:
* **HTML5:** Estruturação semântica do site e das abas de navegação.
* **CSS3:** Design responsivo (adaptável para celulares e computadores) e identidade visual focada no agro sustentável.
* **JavaScript (Vanilla):** Lógica matemática e biológica para processamento dos dados dos sensores simulados.
